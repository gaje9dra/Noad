# noad

A no-ad social community prototype for people and brands to share creative work, ideas, and works in progress.

## Run it

Open `index.html` in a modern browser. No build step or package installation is required.

## In this prototype

- Browse a sample creative feed with For you, Following, and Fresh views.
- Create text posts and choose a community.
- Search posts, sort by popularity or recency, like posts, save posts, and follow creators.
- Sample brand posts are presented as creative stories, not paid placements.
- Preferences and posts are stored in browser `localStorage`.

This is a front-end prototype: accounts, comments, media uploads, moderation, and a shared backend are not implemented. Posts and interactions are local to the current browser.
